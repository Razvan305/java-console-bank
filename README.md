# Java Console Bank

A Java 17 command-line banking application backed by PostgreSQL. It supports creating accounts, depositing and withdrawing funds, transferring between accounts, and viewing balances and transaction history.

## Requirements

- JDK 17 or newer
- Maven
- PostgreSQL

## Database setup

Create a PostgreSQL database and user, then connect to that database and run:

```sql
CREATE TABLE accounts (
    account_number VARCHAR(50) PRIMARY KEY,
    holder_name VARCHAR(200) NOT NULL,
    balance NUMERIC(19, 2) NOT NULL DEFAULT 0
);

CREATE TABLE transactions (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    account_number VARCHAR(50) NOT NULL REFERENCES accounts(account_number),
    type VARCHAR(30) NOT NULL,
    amount NUMERIC(19, 2) NOT NULL,
    target_account VARCHAR(50),
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```

The default connection settings in `DataBaseConfig.defaultPostgresConfig()` are:

- URL: `jdbc:postgresql://localhost:5432/bankdb`
- User: `bankuser`
- Password: `bankpassword`

Update those settings to match your local PostgreSQL setup before running the application. These defaults are for local development only.

## Build and run

Compile the project with Maven:

```bash
mvn clean package
```

Run `com.bank.Main` from your IDE with the project classpath, or configure a Maven/Java run configuration for that main class.

## Using the application

The interactive menu lets you:

1. Create an account with an initial deposit (zero is allowed).
2. Deposit funds.
3. Withdraw funds, provided the balance is sufficient.
4. Transfer funds to another account.
5. View an account's balance and transaction history.
6. Exit.

Amounts are entered as decimal numbers, for example `25.50`. Deposits, withdrawals, and transfers must be greater than zero.
